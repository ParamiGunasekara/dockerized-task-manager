## Project Overview

A hands-on DevOps project focused on building,
containerizing, and deploying a full-stack task
management application using Docker.

## Planned Application Features

- Create new tasks
- View existing tasks
- Update task status
- Delete tasks
- Persistent database storage

## Technology Stack

| Component | Technology |
|---|---|
| Frontend | HTML, CSS, JavaScript |
| Backend | Node.js, Express.js |
| Database | MySQL |
| Web Server & Reverse Proxy | NGINX |
| Containerization | Docker |
| Container Orchestration | Docker Compose |
| CI/CD | GitHub Actions |
| Version Control | Git & GitHub |

## Project Objectives

- Build a multi-container application
- Understand Docker images and containers
- Configure container networking
- Manage persistent database storage
- Implement an NGINX reverse proxy
- Manage environment variables securely
- Implement health checks and monitoring
- Automate testing and builds using GitHub Actions
- Practice troubleshooting and documentation
